# Frontend

Este projeto é o frontend React + Vite do Element Core.

O código permanece em `src/` na raiz para manter compatibilidade com o Figma Make. A raiz do repositório é também a raiz do projeto na Vercel; `vercel.json` define o build e publica `dist/`.

## Deploy

- Framework: Vite
- Comando de instalação: `npm install`
- Comando de build: `npm run build`
- Saída: `dist`
